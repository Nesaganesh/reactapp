# How to View Your Child’s Progress Report

Follow these steps to securely access your child’s progression report.

## Step 1: Generate Your Access Code

1. Visit [flytoez.co.uk/generateaccesscode](https://www.flytoez.co.uk/generateaccesscode).
2. Select or enter your child’s **branch**.
3. Enter your **child’s name**.
4. Submit the details to generate the access code.
5. **Copy and save the access code** somewhere safe. You will need it to open the report.

## Step 2: View the Progress Report

1. Visit [flytoez.co.uk/parentreports](https://www.flytoez.co.uk/parentreports).
2. Select or enter the same **branch**.
3. Enter the same **child’s name** used in Step 1.
4. Enter the copied or saved **access code**.
5. Submit the details to view your child’s progression report.

## Important Information

- If you lose the access code or forget to copy it, please **message Nesa privately** for help.
- Please keep the access code private and do not share it publicly.
- If you have any issues viewing or using the report, please **send a private message** rather than posting the issue publicly.
